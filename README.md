# Karo Pitch - Connecting Startups with Investors

Karo Pitch is a dynamic platform designed to bridge the gap between innovative startups and visionary investors. It provides a comprehensive ecosystem for startups to showcase their ideas, participate in live pitch events, and gain visibility through a centralized leaderboard.

## 🚀 Features

- **Expert Support**: Get guidance from industry experts to refine your pitch.
- **Vast Network**: Access a wide network of potential investors and partners.
- **Leaderboard**: Track top-performing startups and gain recognition.
- **Live Pitch Events**: Participate in real-time pitching sessions to showcase your innovation.
- **Startup Showcase**: A dedicated section to highlight featured startups and their achievements.

## 🛠️ Technologies Used

- **Vite**: For a fast and optimized development environment.
- **React**: Powering the dynamic and responsive user interface.
- **TypeScript**: Ensuring type safety and robust code.
- **shadcn-ui**: Providing a collection of beautiful, accessible UI components.
- **Tailwind CSS**: For utility-first styling and a modern design aesthetic.
- **Lucide React**: For a sleek icon library.

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/Shreya-singh22/karo-pitch-launch.git
   cd karo-pitch-launch
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Start the development server:
   ```sh
   npm run dev
   ```

## 🚀 Deployment

The project is configured for deployment on Vercel. Pushing changes to the `main` branch will automatically trigger a new deployment.
